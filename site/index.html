Frequently asked
questions

A few things to know before making yourself at home.

Why does it need Accessibility access?

macOS requires Accessibility permission to capture, move, and resize other apps’ windows. Offline editing works without it. To capture or restore, allow Persisted in System Settings → Privacy & Security → Accessibility.

What are the limits of desktop restoration?

Desktop movement currently requires macOS 26 and supported system interfaces. On other versions, window positions can still be restored without changing desktops. When available, it restores ordinary Mission Control desktop order and window assignments, creating missing desktops where needed. This is experimental: Mission Control may appear, extra desktops are kept, and full-screen Spaces are preserved. It does not reopen documents or browser tabs.

Will it change my layout automatically?

Auto is off until enabled. It remembers stable changes and restores returning setups, with preset, app, and desktop exclusions. You can also stop a preset learning changes. Restore-only switching is a separate onboarding option: it turns on after your first save if you keep that checkbox selected. Schedules can also apply saved layouts when configured.

Where are my layouts stored?

In Persisted’s Application Support folder on your Mac. Import and export are available in the menu bar panel. Exports may include window titles and document paths, so check before sharing them.

Where can I check the download details?

The download manifest lists the packaged app’s version, supported architectures, minimum macOS version, signature type, and notarization status. Rebuilt development previews may need Accessibility access granted again.

Can I build Persisted myself?

Yes. Download the source, unzip it, and open Terminal in its folder:

./Scripts/build-app.sh release

Requires Xcode or the Xcode Command Line Tools.
Then open build/Persisted.app.
